# WeaveCatcher 0.2.0 Release Notes

**October 29, 2026**

## Widgets

- New **WIDGETS** category with seven ready-made modules: Event calendar, Text box, Rich text, Dropdown, Date & time boxes, Table and Strip.
- **Event calendar** shows the current month with today outlined, and the Manage Events editor highlights event days with a tooltip.
- **Strip** is a full-width banner with a background image — pick from the online strip gallery, upload your own picture, or use an offline gradient. Strips stretch to fill the window when the site is resized.
- **Rich text** lets you format text with bold, italic, underline, headings and bullet lists from Properties.
- **Table** lets you set rows, columns and a header row, then type every cell in Properties.

## Learning & Help

- New **Help** menu: Learn HTML, Learn CSS and Learn JavaScript tutorials, plus a visual step-by-step "How to use WeaveCatcher" tour.

## Improvements

- Every element now has a **CSS class field** in Properties, so exported HTML and CSS can use readable names instead of generated ones.
- New **auto-update toggle** in Settings: with it on, updates download and install while WeaveCatcher runs instead of waiting for the next launch.

## Templates

- Added a `templates/` folder with a stretchable strips template (HTML and CSS versions) and documentation for building flexible, window-resizing layouts in your own sites.

## Downloads

- **Windows:** setup `.exe`, `.msi`, and portable `.zip` for x86, x64, and ARM64.
- **macOS:** universal `.dmg` installer and `.app.zip` archive for Apple Silicon and Intel.
- **Linux x86_64 and AArch64:** `.AppImage`, `.AppImage.zsync`, `.deb`, `.flatpak`, `.pkg.tar.zst`, `.rpm`, and `.tar.gz`.

`SHA256SUMS.txt` contains checksums for the attached files.

Installers are not code-signed. Windows may show a SmartScreen prompt, and macOS may require approval in Privacy & Security the first time the app is opened.
